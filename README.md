# М Маркет.kg — сайт-каталог

Статический сайт (HTML + CSS + JS, без фреймворков) для публикации через GitHub Pages.

## Файлы
- `index.html` — разметка страницы
- `styles.css` — оформление
- `products.js` — **настройки магазина и список товаров** (редактировать здесь)
- `script.js` — поиск, фильтры, корзина, WhatsApp
- `images/` — папка для фотографий товаров

## Как изменить контакты
В начале `products.js` в объекте `SHOP` укажите номер WhatsApp (только цифры, например `996555123456`), ссылку на Instagram, адрес и режим работы.

## Как добавить или изменить товар
Скопируйте любой объект в массиве `PRODUCTS` в `products.js` и поменяйте поля
(`id` должен быть уникальным, `category` — одно из: `care`, `makeup`, `perfume`, `bags`, `household`).
Поле `oldPrice` — старая цена (покажется скидка), `badge` — `"hit"` (Хит) или `"new"` (Новинка).

## Как добавить фото
Положите файл в папку `images/` и укажите путь в поле `image`, например `image: "images/cream.jpg"`.
Если поле пустое, показывается стильная заглушка. Лучше всего подходят квадратные фото.

## Публикация
Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
